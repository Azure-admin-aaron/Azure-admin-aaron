FEATURED PROJECT · TEAM DELIVERY

A clearer foundation for Azure delivery.

The existing Azure environment had limited documentation and needed clearer resource identification and operating standards. Working alongside my cloud team, I helped reshape it around landing zones, naming conventions and resource tagging.

We shared the work on Bicep templates and GitHub deployment workflows. The environment now includes platform, management, online and corporate zones, with developers beginning to deploy application code into the online zone and databases into the corporate zone.

MY CONTRIBUTIONS

The work behind the foundation.

Resource standards

I helped introduce tagging and naming conventions aligned with Microsoft’s Cloud Adoption Framework, making resource purpose easier to understand.

Front Door and Firewall

I helped create Azure Front Door and manage its endpoints. I also helped teammates understand Azure Firewall behavior and how to use rule collections and rules for required service access.

Developer collaboration

I worked directly with developers to begin deploying applications into the online zone and setting up databases in the corporate zone.

What changed: a more structured Azure environment, clearer resource identification, and a shared foundation for infrastructure and application delivery.
