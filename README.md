## Azure foundations: a shared engineering effort

Working alongside my cloud team, I helped reshape an existing Azure environment around clearer standards and landing zones. We shared the work on Bicep templates and GitHub deployment workflows, using infrastructure as code and CI/CD to deploy the environment.

My contributions included:

- **Resource clarity:** helped introduce resource tagging and naming conventions aligned with Microsoft's Cloud Adoption Framework so the purpose of resources was easier to understand.
- **Landing zones and application delivery:** worked with the team on platform, management, online and corporate landing zones. Partnered with developers to begin deploying application code into the online zone and setting up databases in the corporate zone.
- **Networking and application access:** configured virtual networks, VNet peering, and private DNS zones and records. Helped create Azure Front Door and manage its endpoints.
- **Team understanding:** helped teammates understand Azure Firewall behavior and how to use rule collections and rules for required service access.

The result was a more structured Azure environment, clearer resource identification, and a shared foundation for infrastructure and application delivery.
